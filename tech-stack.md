# Tech Stack

## Backend
- **Runtime**: Bun
- **Framework**: Express
- **Language**: TypeScript

## Frontend
- **Framework**: React
- **Language**: TypeScript
- **Bundler**: Vite

## Database
- **Database**: PostgreSQL
- **ORM**: Prisma

## Auth
- **Strategy**: Session-based (express-session + connect-pg-simple)
- No JWTs

## AI
- **Provider**: Anthropic Claude API
